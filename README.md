# Kihira's Toolkit

[![Deploy GitHub Pages](https://github.com/KihiraLove/kihiras-toolkit/actions/workflows/pages.yml/badge.svg)](https://github.com/KihiraLove/kihiras-toolkit/actions/workflows/pages.yml)
[![Ko-fi](https://img.shields.io/badge/Ko--fi-Support%20me-29ABE0?logo=ko-fi&logoColor=white)](https://ko-fi.com/KihiraLove)

A static directory of KihiraLove's OSRS tools, RuneLite plugins, and clan projects. [Open the toolkit](https://kihiralove.github.io/kihiras-toolkit/).

## Run locally

```sh
git submodule update --init
python -m http.server 8000
```

GitHub Actions publishes the site to GitHub Pages. The shared shell and theme come from [kihiras-tools-common](https://github.com/KihiraLove/kihiras-tools-common).

## Artwork and badges

- The Security book is the in-game sprite from the [Old School RuneScape Wiki](https://oldschool.runescape.wiki/w/Security_book). Game artwork belongs to Jagex.
- The simulator and plugin icons come from the associated project repos. The three Clan Clog cards share the supplied Vardorvis artwork.
- RuneLite install badges use Shields.io with the Plugin Hub install endpoints.
